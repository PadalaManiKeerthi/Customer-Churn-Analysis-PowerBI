# Customer Churn Analysis Dashboard - 38.25% Churn Rate

## Overview
Analyzed 1200 telecom customers to find why they leave.

## Tools Used
- Python (Pandas, Colab)
- Power BI

## Key Insights
- **38.25%** Overall Churn
- Electronic Check payment = High Churn
- Fiber Optic Internet = High Churn
